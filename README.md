# Diva Essential Services
Community Engagement Project website for Diva, Thane.

### Included field-survey photos
- Siddhivinayak Multispeciality Hospital
- Metro Hospital & ICU
- Diva Police Facility
- St. Mary School
- Community Garden
- Om Medical & General Store
- Public Toilet facility
- Diva Post Office

### Features
- Search
- Category filters
- Responsive design
- Field-survey photo gallery
- Google Maps search/directions buttons

Open `index.html` with VS Code Live Server.

Before final submission, verify all names, addresses, phone numbers and timings against your field notes. Google Maps buttons currently use Google Maps search queries so they remain useful even where an exact Place ID has not been confirmed.
